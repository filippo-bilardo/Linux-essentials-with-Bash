# 04 — Visualizzazione e Ricerca nei File

## Descrizione

In questo modulo impareremo a leggere e ispezionare il contenuto dei file, a modificarli con l'editor `nano` e a cercare, filtrare ed estrarre dati con strumenti come `grep`, `sort`, `cut`, `wc`, `awk` e `sed`. Sono le competenze fondamentali per lavorare con file di log, dati e configurazioni.

## Obiettivi

Al termine di questo modulo sarai in grado di:

- Visualizzare il contenuto di file con `cat`, `less`, `head`, `tail`, `more`
- Modificare file di testo con l'editor `nano`
- Cercare testo nei file con `grep` e le espressioni regolari di base
- Filtrare, ordinare ed estrarre dati con `sort`, `cut`, `uniq`, `wc`
- Estrarre e analizzare campi con `awk` e trasformare testo con `sed`
